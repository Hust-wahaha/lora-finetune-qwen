# Windows 本地开发依赖清单
#
# 这份文件用于 Windows 本地开发，不替代 requirements.txt 与 pyproject.toml
# （AutoDL 上仍然走 uv sync）。已实测可用范围：
#
#   - 数据生成 / 校验 / 文档维护
#   - 评测体系开发（scripts/eval_compare_full.py 链路）
#   - LoRA 训练 max_length=512：实测 RTX 4060 Laptop 8GB 上峰值 4.28 GiB、
#     约 42 s/step，跑完一个 epoch 的 s800_think 约 28 分钟。显存是 steady-state，
#     与步数无关，可以跑到完整收敛
#
# 尚未在 8GB 上验证（用之前先在 max_length=512 上跑一把确认）：
#
#   - max_length=1024（项目默认）：理论显存估到 6-7 GiB，能挤进 8GB 但余量小
#   - 大 batch / 多 epoch 的长时稳定性（笔记本散热、Windows 驱动）
#
# 正式训练（reference_v1 这种）仍建议上 AutoDL：4090 单步 ~5 s/step，比 4060 快约 8 倍。
#
# 与上游 requirements.txt 的差异：
#   1. torch 从 cu130（Linux only）换成 cu128（有 Windows wheel，向后兼容 RTX 40 系列）
#   2. 显式加上 torchvision 与 qwen_vl_utils —— ms-swift 4.1.3 的 Qwen 加载器隐式
#      要求这两个包；AutoDL 上是被某个传递依赖顺带装上的，Windows 没有
#   3. av 是 qwen_vl_utils 的传递依赖，pin 住为了可复现
#
# 使用方式（PowerShell）：
#   uv python install 3.12
#   uv venv --python cpython-3.12.13-windows-x86_64-none .venv
#   uv pip install --python .venv\Scripts\python.exe `
#     --index-strategy unsafe-best-match -r requirements-windows.txt
#
# 注意：
#   - 不要用 Anaconda 的 Python 做 venv base，会触发 torch c10.dll 初始化失败
#     （见 CLAUDE.md「Windows 本地开发环境」小节）
#   - Windows 训练时必须 `--dataloader-num-workers 0`，与依赖无关，是 multiprocessing
#     spawn 不能 pickle 闭包 hook 的问题
